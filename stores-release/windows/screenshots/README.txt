Windows Store Screenshots
=========================

Required: At least one screenshot (1366 x 768 or larger, PNG format).

How to capture:
  1. Build the app for Windows: cargo tauri build -p mcporb-runtime-app
  2. Run the built MCPOrb Runner
  3. Use Windows Snipping Tool or Win+Shift+S
  4. Save screenshots into this directory as PNG

Suggested screenshots:
  - Library tab showing imported Orbs
  - MCP Config tab with generated STDIO snippets
  - Settings tab showing configuration
