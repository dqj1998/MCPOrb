Mac App Store Screenshots
=========================

Required: At least one screenshot. Recommended for all supported display sizes.

Recommended sizes (any ONE is sufficient to start):
  - 1280 x 800  (non-retina)
  - 1440 x 900
  - 2560 x 1600 (retina)
  - 2880 x 1800 (retina)

How to capture:
  1. Build and run the app: cargo tauri dev -p mcporb-runtime-app
  2. Navigate to the Library tab with at least one Orb imported
  3. Cmd+Shift+4, then Space, then click the window
  4. Save the screenshot into this directory

Suggested screenshots:
  - Library tab showing imported Orbs with search results
  - MCP Config tab showing generated config snippets
  - Settings tab showing configuration options
  - HTTP tab showing a running Orb server

App window size in production: 1040 x 680 (minimum: 860 x 620)
