MCPOrb Runner 1.3.11 - What's New
=================================

---- English ----

Orb hot-reload — no restart needed
------------------------------------------------------------
- Importing an Orb no longer requires restarting the Gateway.
  The app watches for registry changes and picks up new Orbs
  automatically within seconds.
- A periodic fallback ensures Orb discovery works reliably
  even in sandboxed environments.

More reliable process management
------------------------------------------------------------
- Internal process list now supports concurrent access, fixing
  rare race conditions when multiple tools are called at once.

Bug fixes
------------------------------------------------------------
- Fixed stale gateway processes lingering after updates.
  The build script now cleans up old processes before packaging.

MCPOrb Runner 1.3.11 - 日本語
===========================================
Orbホットリロード — 再起動不要
------------------------------------------------------------
- Orbをインポートしてもゲートウェイの再起動が不要になりました。
  レジストリの変更を自動検出し、数秒で新しいOrbを認識します。
- サンドボックス環境でも確実にOrbを検出できるよう、
  定期的なフォールバック機構を搭載しました。

より堅牢なプロセス管理
------------------------------------------------------------
- 複数ツールを同時に呼び出した際の競合状態を修正し、
  内部プロセスリストのスレッドセーフ性を向上させました。

バグ修正
------------------------------------------------------------
- アップデート後に古いゲートウェイプロセスが残る問題を修正。
  ビルドスクリプトがパッケージング前に古いプロセスを自動終了します。

MCPOrb Runner 1.3.11 - 简体中文
===========================================

Orb 热重载 — 无需重启
------------------------------------------------------------
- 导入 Orb 后不再需要重启 Gateway。
  应用自动监听注册表变更，数秒内即可识别新 Orb。
- 增加定期回退机制，确保在沙盒环境下也能可靠发现 Orb。

更稳定的进程管理
------------------------------------------------------------
- 内部进程列表改为线程安全访问，修复多工具并发调用时的
  竞态条件。

问题修复
------------------------------------------------------------
- 修复更新后旧 Gateway 进程残留的问题。
  构建脚本现在会在打包前自动终止旧进程。
