# MCPOrb Runner 1.2.0 更新内容

## 支持通过 HTTP 运行 MCP 服务器

除了原有的 STDIO 模式，现在你还可以通过 **HTTP 协议**运行 MCP 服务器。这意味着你可以连接到远程的 MCP 服务器，而不仅限于本地机器。

打开应用中的 **HTTP** 标签页即可配置主机、端口和传输设置。STDIO 模式的体验保持不变，完全兼容。

## Orb 导入与删除 — 更流畅的体验

导入新 Orb 或删除已有 Orb 后，应用顶部会出现提示横幅，提醒你重启已连接的 MCP 客户端。不再需要猜测更改是否生效 — 你会立即得到明确的提示。

## Store 标签页 — 浏览、搜索和安装 Orb

**Store** 标签页现已正式开放。直接在应用内浏览 MCP Orb 市场：

- **搜索** — 通过 Orb 名称或描述进行全文搜索
- **筛选** — 按标签或 MCP 方法（bm25、tfidf、trigram、vector、knowledge_graph、hybrid）缩小结果范围
- **Orb 详情** — 查看说明、版本历史、可用构件、支持的方法、标签和密码状态
- **密码保护下载** — 私有 Orb 在下载前会弹出密码对话框，应用通过 Store API 验证凭据后再传输
- **一键导入** — 直接从 Store 标签页下载并导入 Orb，无需手动处理 ZIP 文件

在底层，Store 集成已基于专用公共 API（`mcporb.store`）重建，为未来的市场功能奠定了可靠基础。

## 底层改进

- MCP 网关进程现在在日志中清晰标识，运行多个网关时更容易区分各个进程。
- 运行时二进制新增 `--mcp-transport` 参数，确保 HTTP 模式下的指标追踪更加准确。

---

*本次更新聚焦于扩展 MCP 服务器的运行方式。HTTP 模式开启了远程连接的可能性，而改进的导入体验让工作流程更加顺畅。*
