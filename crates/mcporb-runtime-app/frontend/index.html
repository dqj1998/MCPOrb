Choose Your Orb Library Location

To keep your Orb collection visible in Finder and accessible across app updates, MCPOrb Runner stores Orb files in a folder you choose — not inside the hidden app container.

Recommended location: ~/Documents/MCPOrb

Click "Open ~/Documents/MCPOrb" — the file picker will open there. Use the New Folder button if the folder doesn't exist yet, then click Open.
